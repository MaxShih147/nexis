```javascript
  - 取得支撐 STL
  - 更新 Store 狀態

```

**常數定義**：

```javascript
SUPPORT_JOB_TYPE = 'support'
```

### 2. SupportManager.js - 3D 場景管理

**職責**：管理支撐在 3D 場景中的視覺呈現，包含預覽標記和實際網格。

**視覺標記（前端預覽）**：

```javascript
generateSupportMarkers({ numPoints, poissonRadius })
  - 使用 Poisson 圓盤取樣產生點位置
  - 在每個點位建立小球體網格
  - 將本地座標轉換為世界座標

clearSupportMarkers()     // 移除所有標記球體
setMarkersVisible()       // 切換標記可見性
```

**後端支撐網格**：

```javascript
addSupportMesh(stlBlob)   // 主要方法 - 加入支撐網格
  - 移除既有支撐網格
  - 解析 STL blob 為 BufferGeometry
  - 建立 THREE.Mesh（綠色材質）
  - 透過矩陣轉換將網格從世界座標轉為模型本地座標
  - 計算包圍盒

removeSupportMesh()       // 移除支撐網格
setSupportMeshVisible()   // 切換網格可見性
hasSupportMesh()          // 檢查是否有支撐網格
getSupportMesh()          // 取得網格物件
setSupportMeshColor()     // 變更網格顏色
setSupportMeshOpacity()   // 變更網格透明度
```

**內部輔助方法**：

```javascript
loadSupportMeshFromBlob() // 將 STL blob 轉換為 THREE.Mesh
_createSupportMesh() // 建立帶材質的網格
_attachSupportMesh() // 將網格附加到模型或場景
_disposeSupportMesh() // 清理網格資源
```

**材質設定**：

```javascript
supportMeshMaterial = new MeshPhysicalMaterial({
  color: 0x4CAF50, // 綠色
  opacity: 0.8,
  transparent: true,
  metalness: 0.1,
  roughness: 0.5
})
```

### 4. poissonDiskSampling.js - 取樣演算法

**職責**：在網格表面產生均勻分佈的點取樣。

```javascript
poissonDiskSampling(geometry, numPoints, poissonRadius)
  - 從幾何中提取頂點位置
  - 計算幾何中心
  - 使用 kd-tree 進行快速最近鄰搜尋
  - 隨機選取三角形
  - 使用重心座標在三角形內產生隨機點
  - 確保點之間的最小距離（poissonRadius）
  - 回傳最多 numPoints 個取樣點
```

**回傳格式**：

```javascript
// 回傳 [x, y, z] 座標陣列
[[x1, y1, z1], [x2, y2, z2], ...]
```

### 5. backendService.js - API 層

**支撐相關 API**：

## 狀態管理

### 狀態來源

支撐狀態有兩個來源，透過 computed 屬性合併：

```javascript

hasSupportMesh = computed(() =>
  backendStore.supportState.hasSupportMesh
  || supportManager.hasSupportMesh()
```

| 控制項 | 檔案 | 狀態 |

## 架構設計模式

### 1. 分層抽象

- **服務層** (supportService.js)：後端通訊抽象
- **管理器層** (SupportManager.js)：3D 渲染抽象
- **Store 層** (useBackendStore.js)：狀態管理
- **API 層** (backendService.js)：HTTP 通訊

### 2. 關注點分離

```
UI 元件    →  不處理業務邏輯，只處理使用者互動
服務層     →  協調業務流程，不處理 HTTP 細節
API 層     →  只處理 HTTP 通訊，不處理業務邏輯
3D 管理器  →  只處理 3D 渲染，不處理後端通訊
Store      →  只處理狀態，不處理業務邏輯
```

### 3. 座標空間轉換

後端產生的支撐網格是世界座標，需要轉換到模型本地座標：

```javascript
// SupportManager.js - _attachSupportMesh()
selectedObject.updateMatrixWorld(true)
const inverseWorld = selectedObject.matrixWorld.clone().invert()
supportMesh.geometry.applyMatrix4(inverseWorld)
```

### 4. 輪詢模式

使用輪詢等待後端非同步任務完成：

```javascript
pollJobUntilComplete(jobId, {
  interval: 500, // 輪詢間隔
  timeout: 120000, // 最大等待時間
  onProgress: cb // 進度回呼
})
```

### 5. 狀態同步

多來源狀態透過 computed 屬性同步：

```javascript
// Store 狀態 + Manager 狀態 = 最終狀態
hasSupportMesh = store.hasSupportMesh || manager.hasSupportMesh()
```
