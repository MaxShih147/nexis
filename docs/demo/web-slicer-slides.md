## 5｜我們的解法：Web Slicer

- 版本永遠最新，無需維護

## 6｜架構：雲端 + 本地混合 Cloud + Local Hybrid

- **雲端 Cloud**：模型/切片檔儲存 + 帳號系統 Account System（團隊協作、版本統一）
- **本地 Local Agent**：切片等重運算跑在本地 → 速度快、不佔雲端成本、原始資料留在本地
- 兼顧效率、成本與資料掌控

🎨 簡單架構圖：使用者 → 瀏覽器 UI →（雲端儲存/帳號）+（本地 Agent 算力）。

## 12｜功能地圖 Feature Map

- **匯入**：多格式 STL/OBJ/3MF、多模型 Multi-model
- **定位**：自動定位 Auto-Orient（板用瀏覽器算、導板用本地引擎）
- **牙科處理**：挖空 Hollowing、排水孔+蜂巢 Drain/Hex、鑽孔 Drilling、切平/底部 Base&Cut
- **編輯**：文字刻字 Text Emboss、支撐 Support、剖面 Clipping、面選取
- **輔助**：超界標示 Out-of-bounds、復原重做 Undo/Redo
- **輸出**：逐層預覽 Layer Preview、預估時間/樹脂量、PRZ 匯出
