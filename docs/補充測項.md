- 機台選擇畫面
    - 切換牙科模式時，樹脂自動更改成選取該模式下第一個樹脂
    - 切換機台時，牙科模式不變
    - 切換機台時，若該機台在該牙科模式下有目前選擇的樹脂，則選取相同樹脂
    - 切換機台時，若該機台在該牙科模式下沒有目前選擇的樹脂，則顯示confirm dialog
        - confirm dialog需顯示「目前樹脂」及「該機台在該模式下的第一個樹脂」
        - 按continue則選取該機台在該模式下的第一個樹脂
        - 按cancel時回退到原本的機台、牙科模式及樹脂
    - 所有機台在所有牙科模式下都必須有樹脂（至少要有default profile）
    - 直接把dialog關掉，仍然有選擇到機台、牙科模式及樹脂（驗證方式：右下角summary、一鍵處理行為正確）
    - 顯示匯入參數按鈕
        - 按下去會出現選擇檔案視窗
        - 只能選擇xml檔案
        - 選擇後可輸入樹脂名稱及選擇牙科模式
        - 按cancel退回
        - 按import後選單內出現並選取該樹脂
        - 匯入的樹脂出現在正確的機台及牙科模式底下
        - 關閉modal後列印參數符合上傳的xml列印參數

- 匯入模型
    - 將檔案拖曳到網頁上時，顯示顏色遮罩及文字「drop 3d model to load」
    - 確認拖曳後會顯示對話框或檔案選擇介面，讓使用者可選擇或確認要上傳的模型←目前沒有這個喔
    - 場上有模型時，模型匯入按鈕為disabled
    - 場上有模型時，再次拖曳匯入模型會顯示錯誤，並且不會匯入該模型
- 3D view滑鼠互動
    - 模型點一下，model list該item會顯示選取
    - 模型點兩下，model list該item會顯示選取，並出現旋轉gizmo
    - 場景點兩下，模型取消選取，若有gizmo則gizmo消失
    - 場景點一下，無作用
    - gizmo點一下，不取消選取模型
- gizmo
    - hover到gizmo上時要有視覺提示
- 打洞
    - 在打洞模式下，hover到模型上應顯示圓柱
    - 圓柱應垂直於hover到的面
    - 沒有hover到模型時不顯示圓柱
    - 點選hide cylinder時，text變成show cylinder
    - 點選hide cylinder時，hover到模型上不顯示圓柱
    - 點選hide cylinder時，點選模型不會產生圓柱/洞
    - 拖曳模型時，洞會跟著模型移動
    - 縮放模型時，洞會跟著變形
- 鏤空
    - 在鏤空模式下，模型應為半透明
    - 沒有選取模型時，點選hollow會跳出錯誤提示
    - hollow完原模型內應該要有藍色的hollow mesh
    - hollow完，拖動模型截面顯示器，應可看出有hollow
    - 跳出hollow模式時，模型恢復不透明，看不到藍色的hollow mesh
- 一鍵處理
    - 沒有選取模型時，點選一鍵處理會跳出錯誤提示
    - 咬合板/手術導板/牙冠牙橋一鍵處理後進入支撐檢視模式，此時不可編輯模型、底部工具列及模型面板
- slicer button
    - 無模型時點選出現錯誤提示
    - 有模型時點選，出現進度條，切片完成後跳轉到預覽頁面
- 模型編輯面板
    - 旋轉
        - 選面貼底
            - 點選選面貼底後，進入選面貼底模式，icon變綠
            - 點選選面貼底後，選面朝上icon不可是綠色
            - 在選面貼底模式，hover到模型上時，將要貼底的面會顯示綠色
        - 選面朝上
            - 點選選面朝上後，進入選面朝上模式，icon變綠
            - 點選選面朝上後，選面貼底icon不可是綠色
            - 在選面朝上模式，hover到模型上時，目前hover到的面會顯示綠色，並顯示一個綠色的箭頭，該箭頭與hover到的面垂直
